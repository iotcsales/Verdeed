Welcome to Verdeed

Three steps to get from "I just downloaded this" to actually using it.

1

Read the Getting Started Guide

Open VERDEED-GETTING-STARTED.html first. It covers what you're actually buying, what it costs to run, and how each of the seven modes works — five minutes, worth reading in full before you open the tool itself.

2

Set Up Your API Access

Verdeed runs on your own Anthropic API key — a separate, free account you create directly with Anthropic, with a small prepaid credit balance (the Getting Started guide walks you through this in under two minutes). Verdeed has no recurring subscription or monthly fee. Your purchase gives you access to the Verdeed application. AI usage is powered through your own Anthropic API account and prepaid credits.

3

Install Verdeed — this is the step that matters

Open iotcsales.github.io/Verdeed in Safari, tap the Share icon, then Add to Home Screen. This takes about ten seconds and creates a real Verdeed icon on your Home Screen — after that, you open Verdeed exactly like any other app: tap the icon, it opens full-screen, no browser bar, no downloads folder.

You'll need an internet connection to actually run an analysis.

This is the way we recommend using Verdeed — it's the fastest, most reliable, and most app-like experience available, and it's the only path we've fully tested end to end.

4

Use Verdeed

Open Verdeed from your Home Screen icon, paste in your API key, and choose the mode you need — Analyze, Draft, Compare, Due Diligence, Rental Review, or Batch Analyze. You can save your results to History for later, and every result can also be printed, downloaded, or shared.

The downloaded VERDEED.html file in this package is included as a personal backup copy. On iPhone, opening it directly from the Files app may launch a preview mode that displays the page but doesn't run its calculations. If that happens, it's not a fault in your download — just use the Home Screen icon from Step 3 instead, which always works correctly.

Your Verdeed workspace also includes four free standalone real-estate calculators — Veritally, Clearsum, Truestay, and Landtally. No API key, no subscription, and available independently of a Verdeed purchase — accessible directly from inside Verdeed.
