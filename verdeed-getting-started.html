STEP-BY-STEP

1 SET UP YOUR API ACCESS (one-time, ~5 minutes)

Create your account and add credits

  1. Go to console.anthropic.com
  2. Sign up with your email (or log in if you already have an account) — this part is free
  3. Go to Settings → Billing, add a card, and purchase prepaid credits — $5 minimum
  4. Back in the main menu, find "API Keys"
  5. Click "Create Key", give it any name (e.g. "Verdeed"), and copy the key that appears — it will look like sk-ant-...
  6. Save it somewhere safe for a moment — a notes app, or just keep the tab open — you'll paste it into Verdeed in Step 4

This is separate from any Claude.ai subscription you might have — API credits and a Claude.ai plan are two different things.

DESKTOP / LAPTOP
2 OPEN THE FILE

Just double-click it

Find verdeed.html wherever you saved your download, and double-click it. It opens directly in your default browser (Chrome, Edge, Safari, Firefox — any of them work). That's it — no installation, no account, nothing else to set up.

PHONE / TABLET (optional)

A quick note if you're on mobile

Verdeed is built to work best on a computer — reviewing and drafting documents just suits a bigger screen better. If you only have a phone, opening a downloaded HTML file directly can be finicky depending on your device (mobile browsers sometimes refuse to open local files properly). If you hit that wall, the most reliable phone-friendly option is to host the file yourself for free using a service like GitHub Pages, or simply use Verdeed from a laptop/desktop when you can.

3 READ AND ACCEPT THE NOTICE

A short screen appears first

Verdeed opens with a short, friendly notice on what it does well and where to stay careful — like any AI, it's worth double-checking the details that matter, and having a lawyer review anything before you sign, stamp, or register it. Tick the box and click "Enter Verdeed" to continue. You'll see this each time you open the file — it's a quick reminder, not a one-time gate.

4 PASTE YOUR API KEY

Paste it in and you're ready

At the top of the tool, there's a field labeled "API KEY." Paste the key you copied in Step 1. It stays in your browser for this session only — it is never saved to disk, never sent anywhere except directly to Anthropic, and disappears when you close the tab. You'll need to paste it in again next time you open the file.

THE FIVE MODES

ANALYZE
Paste text, or upload a scan/photo/PDF of a document. Get classification, extracted facts, plain-English clause explanations, flagged issues, and a risk score — every conclusion marked Verified, Probable, Estimated, or Unknown.
DRAFT
Choose from a wide range of real estate document types — sale deeds, leases, POAs, affidavits, development agreements, and more — describe what you know, and get a fully structured first draft back. Anywhere you didn't provide a fact, it inserts a clear placeholder like [SURVEY NUMBER] instead of guessing — followed by a Review Notes section listing everything still left to fill in. It's a real starting point, not a finished document to sign.
COMPARE
Paste or upload two documents — e.g. a sale deed and a mutation record — and see a field-by-field match/mismatch check on names, survey numbers, area, boundaries, and dates.
DUE DILIGENCE
Combines Analyze and Compare: one primary document plus up to two supporting records, bundled into a single report with a title chain summary, risk breakdown, and recommendation.
RENTAL REVIEW
Upload a rent agreement, lease deed, or Leave & License agreement and review it from your side of the deal — as the Tenant protecting your deposit and exit terms, or as the Owner protecting your property and income. Works for rental documents from any country, not just India.

FREQUENTLY ASKED

How much will this actually cost me to run?
See the full cost breakdown table near the top of this guide — it ranges from about $0.01 for a short text-only analysis up to about $0.30 for the most demanding case (a Due Diligence report built from several lengthy scanned PDFs). Most everyday use falls in the $0.03–$0.09 range. There's no subscription — you only pay Anthropic for what you actually use.
Is my API key safe?
It lives in your browser's memory for the current tab only. It's never written to a file, never sent to any server other than Anthropic's, and disappears when you close the tab. Don't share the file with your key still typed into the field, and don't share your key with anyone else.
Does it work without internet?
No — every analysis needs a live connection to reach Anthropic's servers.
Can it read handwritten documents?
Reasonably well for clear handwriting, uploaded as a photo or scan. Very poor handwriting or heavily degraded scans may be misread — always check extracted facts against the original.
Does it check government records automatically?
No. It only works with documents you provide yourself. It cannot independently pull mutation records, encumbrance certificates, or other registry data.
Can it detect a forged signature or a fake stamp?
No — that requires specialized forensic tools, not a language model. Treat Verdeed as a first-pass reading and organizing aid, not a fraud detector.

IF SOMETHING GOES WRONG

"I opened the file but nothing happens when I click things"

You're most likely looking at a preview of the file rather than the file actually running in a browser — this happens when a file manager, email app, or messaging app shows you a quick look at the page without loading it properly. The fix is to make sure it opens in an actual browser app (Chrome, Safari, Edge, Firefox):

  • On desktop: right-click the file → "Open with" → choose your browser by name
  • On mobile: use the share icon (square with an arrow) rather than just tapping the file, and look for your browser app in the share list

"The 'Enter Verdeed' button doesn't respond, or a page I know I fixed still looks old"

This is almost always your browser showing you a cached (saved, outdated) version of the page rather than the current one. Try:

  1. Force-refresh the page (hold down the reload button, or close the tab completely and reopen the file fresh)
  2. If that doesn't help, open the file in a Private/Incognito browser window — this guarantees you're seeing the real, current version with nothing cached

"I'm on a phone and it just won't open properly no matter what I try"

Some phones are genuinely stricter than others about opening local files in a full browser. If you've tried the share-icon method above and it's still not working, the most reliable fallback is simply switching to a laptop or desktop for this — Verdeed is built with that as the primary experience anyway. If mobile access is important to you, ask about a hosted version.

"I get an error message when I try to run an analysis"

Check these three things, in order:

  1. Is your API key pasted in correctly? It should start with sk-ant- and have no extra spaces before or after it.
  2. Have you added credits? A $5 minimum prepaid top-up is required in your console's Settings → Billing before any request will work — creating the key alone isn't enough.
  3. Are you connected to the internet? Every request needs a live connection.

If all three check out and it's still failing, the error message itself usually explains what went wrong — feel free to reach out with the exact message and we'll help.
